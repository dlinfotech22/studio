# **App Name**: Contabilidade Leve

## Core Features:

- Revenue Entry: Daily recording of revenue with service provision payments.
- Expense Entry: Daily recording of expenses, including salaries, suppliers, utilities, rent, etc.
- Intelligent Financial Reporting: Tool for smart report generation that creates custom monthly and annual overviews of financial data with minimal setup required.
- Dashboard Visualization: Visual dashboard presenting monthly and annual revenue, expenses, and profit.
- Year-End Report: Generation of a comprehensive end-of-year report with revenue, expenses, and profit analysis.
- Customizable Reporting Period: Allow users to define a custom date range for data export and report generation.
- Excel Export: Functionality to export selected period's data to an Excel spreadsheet.
- PDF Report Generation: Button to generate the current year's complete financial report in PDF format.

## Style Guidelines:

- Primary color: Muted blue (#6699CC) to inspire trust and stability.
- Background color: Very light grey (#F2F2F2), close in hue to the primary color but nearly desaturated, for a clean interface.
- Accent color: Soft green (#8FBC8F), an analogous hue that evokes growth and financial health. Slightly lighter than the primary.
- Font pairing: 'Inter' (sans-serif) for both headlines and body text. Clean, modern, and highly readable.
- Left sidebar menu for easy navigation between sections (Dashboard, Revenue, Expenses, Reports).
- Consistent use of simple, line-based icons to represent different categories of transactions and reports.
- Subtle transitions and animations on data updates and report generation to enhance user experience.
